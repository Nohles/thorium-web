Reading modes

Single Page: 

    This mode is a single page view. So the image is displayer in the center of the screen. 

```
┌────────────────────────────────────────┐
│              viewport                  │
│                                        │
│            ┌─────────────┐             │
│            │    page     │             │
│            └─────────────┘             │
│                                        │
└────────────────────────────────────────┘
```

    Scale types - 
        
        Fit Width: 
            -The image is displayed up to width of the screen if the pixels are less it stays at orginal size. 
            -If the image is wider than the screen, it will be scaled down to fit the screen.
            - if the image is taller than the screen, then it will allow the user to scroll down to see the rest of the image.
        Fit Height: 
            - The image is displayed at the height of the screen.
            - unless the image is wider than the screen then the image will be bound by the width of the screen.

        Fit Screen: 
            - The image is displayed at the width and height of the screen.
            - unless the image is taller than the screen then the image will be bound by the height of the screen.
        Original Size: 
        - The image is displayed at the original size.
        - if the image is wider than the screen, it will be scaled down to fit the screen width.
        - if the image is taller than the screen, the user will be able to scroll down to see the rest of the image.



Double Page: 
    This mode is a double page view. So the image is displayed in two columns. 50% of the screen width each.

```
┌────────────────────────────────────────┐
│              viewport                  │
│  ┌─────────────────┬─────────────────┐ │
│  │     left        │      right      │ │
│  │     page        │      page       │ │
│  │                 │                 │ │
│  └─────────────────┴─────────────────┘ │
└────────────────────────────────────────┘
```

Continuous Vertical:

```
        ┌───────┐
        │ page  │
        │   1   │
        ├───────┤
        │ page  │   ↑
        │   2   │   │  vertical
        ├───────┤   │  scroll
```
